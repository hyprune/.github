# Hyprune organization defaults

`profile/README.md` is the public org profile. Root contribution, conduct, security and template files provide GitHub community defaults for repositories without local overrides.

Before opening community participation, provision and test `conduct@hyprune.com` (currently an explicit placeholder), appoint a responder, and enable/test GitHub private vulnerability reporting. No personal email address is published. Review [docs governance](https://hyprune.com/governance/) and the eight proposed RFCs.
