# Hyprune organization defaults

`profile/README.md` is the public org profile. Root contribution, conduct, security and template files provide GitHub community defaults for repositories without local overrides.

conduct@hyprune.com and security@hyprune.com reach the project steward, and GitHub private vulnerability reporting is enabled on the code repositories. No personal email address is published. Review [docs governance](https://hyprune.com/governance/) and the [RFCs](https://hyprune.com/rfcs/0001-umbrella/) (RFC-0001 to RFC-0009 accepted).
